# 📅 Aether Calendar AI (HTML/웹 버전)

> **설치나 외부 서버 없이, 더블 클릭만으로 브라우저에서 바로 작동하는 스마트 AI 캘린더**입니다.  
> 100% 오프라인 한국어 자연어 처리 AI 비서, 모던 Fluent Design & Glassmorphism 디자인, 월간/주간/목록 뷰 및 로컬스토리지 영구 저장을 지원합니다.

---

## 🚀 빠른 실행 방법

### 방법 1. 원클릭 실행 (추천)
- 폴더 안의 **`run_web.bat`** 파일을 더블 클릭하면 기본 웹 브라우저(Chrome, Edge 등)에서 즉시 실행됩니다.

### 방법 2. 직접 열기
- **`index.html`** 파일을 더블 클릭하여 웹 브라우저로 엽니다. (별도의 웹 서버나 파이썬 설치 없이도 완벽하게 작동합니다)

---

## ✨ 핵심 기능

1. **🖥️ 다채로운 3대 캘린더 뷰**
   - **월간(Month) 뷰**: 일요일 시작 7열 달력, 주말 색상 구분, 오늘 날짜 하이라이트, 날짜 클릭 시 일정 추가
   - **주간(Week) 뷰**: 7일간 07:00~22:00 시간대별 타임라인 그리드, 시간 블록 클릭으로 일정 등록
   - **목록(Agenda) 뷰**: 다가오는 일정을 날짜별 카드 형태로 정렬하여 한눈에 파악 및 수정/삭제

2. **🤖 100% 오프라인 지능형 한국어 AI 비서 (우측 AI 도크)**
   - API 키나 인터넷 연결 없이도 일상 대화체 완벽 분석:
     - *"내일 오후 3시 강남역에서 영희와 커피 미팅 1시간 추가해줘"*
     - *"오늘 저녁 7시부터 8시반까지 헬스장 운동 등록해줘"*
     - *"오늘 일정 요약해줘"* (당일 일정 브리핑 및 소요시간 통계)
     - *"내일 비어있는 시간 2시간 찾아줘"* (09:00~18:00 빈 슬롯 탐색)
     - *"내일 회의 취소해줘"* (일정 검색 및 자동 삭제)
   - **일정 충돌 감지**: 시간이 겹치는 기존 일정이 있을 경우 자동 경고 안내
   - **원클릭 빠른 프롬프트 칩**: 브리핑, 빈 시간 찾기, 회의 등록 등을 버튼 하나로 즉시 실행
   - **인터랙티브 일정 카드**: AI가 등록한 일정 카드에서 `[📅 캘린더에서 날짜 보기]`를 누르면 해당 날짜로 즉시 이동

3. **🌓 라이트 & 다크 모드 지원**
   - 상단 우측 `🌙 / ☀️` 버튼으로 다크 모드와 라이트 모드를 자유롭게 전환할 수 있습니다.
   - 사용자 선호 테마는 자동으로 저장되어 새로고침 후에도 유지됩니다.

4. **💾 영구 데이터 저장 & 백업 지원**
   - 모든 일정과 설정은 브라우저의 `LocalStorage`에 영구 보존됩니다.
   - 상단 `⚙️ 설정` 메뉴에서 전체 일정을 `JSON 파일 백업`하거나, `iCalendar(.ics)`로 내보내어 구글 캘린더/애플 캘린더와 연동할 수 있습니다.

5. **⌨️ 단축키 안내**
   - `Ctrl + N`: 새 일정 추가 모달 열기
   - `Ctrl + T`: 오늘 날짜로 즉시 이동
   - `Ctrl + F`: 일정 검색창으로 포커스
   - `Ctrl + Shift + A`: AI 비서 도크 접기 / 펼치기
   - `Esc`: 열려있는 모달 닫기
